# Syed Tabrez Pasha — Apple-Grade Portfolio in Flutter

A production-grade, responsive portfolio website engineered exclusively with **Flutter Web**, Dart, and Apple Human Interface Design principles.

## Features
- **Apple Keynote Typography & Theme**: Obsidian `#000000`, Space Gray `#121214`, and Apple Blue `#2997FF`.
- **Interactive iPhone 16 Pro Hardware Mockup**: Live tab switching between InsightBlog, FlowTask Pro, and Connect WebChat.
- **Apple Silicon M-Series Bento Grid**: Clean Architecture (Presentation, Domain, Data), Hive NoSQL cache, and real-time WebSockets.
- **Projects Matrix**: Filterable lineup with GitHub links for all repositories (`tabrezcool6`).
- **macOS Code Inspector**: Dart snippets showing BLoC state streams, Hive repositories, and widget pump tests.
- **Responsive on All Devices**: Mobile phones, tablets, and desktop displays.

---

## Quickstart

### 1. Install Dependencies
```bash
flutter pub get
```

### 2. Run Locally on Flutter Web
```bash
flutter run -d chrome
```

### 3. Deploy to GitHub Pages (`tabrezcool6.github.io`)
```bash
flutter build web --base-href "/tabrezcool6.github.io/" --release
```

Copy the generated files from `build/web/` directly into your `tabrezcool6.github.io` repository root or `gh-pages` branch.
